# Essential Terminal Commands
### The ones you'll use every day (Level 1) and frequently (Level 2)

---

## 🔥 Level 1 — Daily use

### Navigation
```bash

cd folder            # Enter a folder
cd ..                 # Go up one level
pwd                   # Show the current folder (print working directory)
ls                    # List files (Mac/Linux)
dir                   # List files (Windows)
clear                 # Clear the screen (Mac/Linux)
cls       
            # Clear the screen (Windows)
```

### Running Python
```bash
python3 file.py       # Run a script (Mac/Linux)
python file.py        # Run a script (Windows)
```

### Git — the combo you'll repeat constantly
```bash
git status                  # Show which files you changed
git add .                    # Stage ALL changes
git commit -m "message"      # Save the changes with a description
git push                     # Upload the changes to GitHub
git pull                     # Download changes from GitHub
```

---

## ⚡ Level 2 — Frequent use (several times a week)

### Files and folders
```bash
mkdir name            # Create a new folder
touch file.py          # Create an empty file (Mac/Linux)
cp file destination    # Copy a file
mv file destination    # Move or rename a file
rm file                # Delete a file (careful, no recycle bin!)
```

### Git — review and history
```bash
git log --"online":    # Show commit history, summarized
git diff             # Show which lines you changed before committing
```

### Python — installing libraries
```bash
pip install package                   # Install a library
pip install -r requirements.txt       # Install all project dependencies
```

### VS Code
```bash
code .               # Open the current folder in VS Code
```
